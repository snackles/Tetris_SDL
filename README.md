# Tetris_SDL
Classic Tetris written using SDL2 without using OOP

Linux:
> make -f Makefile.linux
> ./tetris

MacOS:
> make
>make run

Navigation:

Move left - Left arrow
Move right - Right arrow
Down faster - Down arrow
Hard drop - Spase
Rotate left - Z
Rotate right - X

Pause - P
Restart - R (it works during a pause or after a loss)
