# Tetris_SDL
Classic Tetris written using SDL2 without using OOP

# Install
Need to install: SDL2, SDL2_ttf

# Run
Linux:
>make -f Makefile.linux

> ./tetris

MacOS:
>make

>make run

Windows:
>make -f Makefile.win

>./tetris

# Navigation:

A - Move left

D - Move right

S - Down faster

W - Hard drop

Q - Rotate left

E - Rotate right

P - Pause

R - Restart (it works during a pause or after a loss)

ESCAPE - Qiut
