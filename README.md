# Tetris_SDL
Classic Tetris written using SDL2 without using OOP

# Install
Need to install: SDL2, SDL2_ttf

# Run
Linux:
```bash
make -f Makefile.linux
./tetris
```
MacOS:
```bash
make
make run
```
Windows:
```bash
make -f Makefile.win
./tetris
```
# Navigation:
W - Hard drop

A - Move left

S - Down faster

D - Move right

Q - Rotate left

E - Rotate right

P - Pause

R - Restart (it works during a pause or after a loss)

ESCAPE - Qiut
