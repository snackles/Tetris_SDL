# Tetris_SDL
Classic Tetris written using SDL2 without using OOP

# Install
Need to install: SDL2, SDL2_ttf

# Run
Linux:
>make -f Makefile.linux

> ./tetris

MacOS:
>make

>make run

Windows:
>make -f Makefile.win

>./tetris

Navigation:

Move left - A

Move right - D

Down faster - S

Hard drop - W

Rotate left - Q

Rotate right - E

Pause - P

Restart - R (it works during a pause or after a loss)

Qiut - ESCAPE
